Quick guide to using the project dashboard.

01

Home

Read the project introduction and use the buttons to open image analysis or the dashboard.

02

Analyze Image

Select an aerial image and run the complete AI pipeline. The result is also saved to Analysis History.

03

Dashboard

View flood classification, full-image segmentation, object counts, flood impact and emergency assessment.

04

Reports & History

Reports and Analysis History show completed analyses. History can be cleared from the history page.

05

Settings

Use Account, Appearance, AI analysis preferences and Data & Reports controls. Theme preference is remembered in the browser.

06

Important note

Emergency severity and rescue priority are project-defined rules for academic demonstration; they are not official emergency-service standards.
